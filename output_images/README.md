# 📁 Output Images Folder

Thư mục này chứa các ảnh được generate từ ứng dụng.

## Tự động lưu

Mỗi ảnh được generate thành công sẽ **tự động** được lưu vào đây.

## Format tên file

```
{prompt_safe}_{timestamp}.png
```

Ví dụ: `A_cute_bear_2026-01-30T10-30-45-123456.png`

## Quản lý

- Các file ảnh **không** được commit vào git (đã ignore)
- Bạn có thể xóa các file cũ để tiết kiệm dung lượng
- Mỗi file có timestamp unique nên không bị trùng tên
